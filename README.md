# Relian-Client-V1
Lunar + Hack client


## In-game client runtime

The separate `relian-client-fabric/` module is the first in-game runtime milestone for Minecraft Java 1.21.1 on Fabric. It adds a Right Shift HUD editor with FPS, coordinates, keystrokes, and armor durability panels. Users can toggle, reposition, resize, and recolor these panels. See [the runtime README](relian-client-fabric/README.md) for build instructions and current limitations. This does not yet provide a complete game launcher or a custom Minecraft resource-loading splash.
