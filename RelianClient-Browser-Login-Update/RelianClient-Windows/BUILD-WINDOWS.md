# Build Relian Client for Windows

## Requirements
- Windows 10/11 x64
- JDK 21
- Gradle 8.10.2 (the GitHub Actions workflow installs it automatically)

## Build from GitHub
1. Create a GitHub repository and upload this project.
2. Open **Actions** and select **Build Relian Client for Windows**.
3. Select **Run workflow**.
4. When it finishes, open the workflow run and download the `RelianClient-Windows-Installer` artifact.
5. The artifact contains the Windows installer generated by `jpackage`.

## Microsoft browser sign-in setup
Relian uses the system browser with OAuth 2.0 authorization-code flow and PKCE. It does not collect or handle the user's Microsoft password.

Before sign-in can work, the Relian publisher must register a Microsoft Entra application:
- Supported account type: personal Microsoft accounts (or the desired supported account types).
- Platform: Mobile and desktop applications / public client.
- Configure the loopback `http://localhost` redirect for a desktop app.
- Use the app's **Application (client) ID**; do not create or ship a client secret for this public desktop client.

Then copy `auth.properties.example` to `auth.properties` and replace `YOUR_APPLICATION_CLIENT_ID` with the registered application ID. Alternatively set `RELIAN_MS_CLIENT_ID` in the process environment. `auth.properties` is ignored by Git.

**Important:** This code currently completes Microsoft identity OAuth only. A production Minecraft launcher must still implement and test the Xbox Live, XSTS, Minecraft Services login, entitlement/profile checks, refresh-token handling, and safe credential storage before enabling game launch. The current Play button remains a placeholder. Do not describe this build as a fully working Minecraft launcher yet.

## Installer
The Gradle `jpackage` task creates a Windows `.exe` installer and bundles a runtime image. The installer is configured to add Start Menu and desktop shortcuts.
